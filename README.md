# VPX PRO MASTERING PROCESSOR

Experimental JUCE VST3 stereo live audio processor. **Not yet tested in VirtualDJ 2020.** VirtualDJ 2020 may require VST2, which is not generated by this project. Do not use an untested build at a live concert.

## Build
Open the Actions tab and run **Build Windows VST3**. Download the artifact from the completed workflow run.

## Features
4-band EQ, subsonic filter, compressor, sample-peak ceiling, five presets, bypass. The limiter is **not true-peak**, is not a speaker-protection DSP and cannot replace properly configured amplifiers, crossovers, and speaker limiters.
